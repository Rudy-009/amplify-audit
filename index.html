How it works

1

Collect

~/.claude/projects/**/*.jsonl에서 사용자 프롬프트만 추출. noise, tool 결과, 슬래시 명령 제외.

2

Classify

AI가 각 프롬프트를 Amplify / Offload / Bypass / Neutral / Ambiguous로 판정. 위임형은 3-gate 검증.

3

Render

비율 + 타임라인 + 태그별 분류를 담은 HTML 리포트 생성. ~/amplify-audit/ 에 저장.
